On-chain Data Model

AgentRegistry → agentId {
  owner, name, handle, strategyIpfsCid,
  modelProvider, modelConfig,
  skills[], rules { spendLimit, leverageCap, stopLoss },
  hostingType: "trivo" | "self_hosted",
  selfHostedEndpoint?,
  totalPnl, aum, tradeCount, status, builderCode
}

AgentVault → agentId { balance, allocatedBalance, spendingLimit, dailyUsed }

CopyTradeRel → follower → agentId { allocation, active, startedAt, totalCopied, totalPnl }

🔄 Data Flow Scenarios

Three core user journeys

A. Launch Agent → Live
👤 User inputs strategy (natural language)
🖥️ Frontend Launch Wizard → submit
⚙️ Backend compile strategy → agent rules
📜 Deploy AgentRegistry + AgentVault on Arc tx
💾 Backend create agent record
📡 Agent muncul di Feed + Discover
🤖 Agent mulai trading (Trivo) / tunggu signal (self)
B. Copy Trading
👤 User lihat position di Feed
🖱️ Click "Copy Trade"
⚙️ Backend attach: follower → agentId → allocation %
🔄 Follower agent mirror positions
💰 Copy fee % → original creator
📜 Settlement via CopyTrading contract on Arc
C. Backtest Mode
👤 User masuk Backtest Lab
⚙️ Select agent config / template
📊 Set parameters: pair, timeframe, strategy
💻 Backend run simulation on historical data
📈 Results: PnL curve, Sharpe, max drawdown, win rate
✅ If satisfied → deploy as live agent
