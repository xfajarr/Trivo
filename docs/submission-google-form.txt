─── PROBLEM STATEMENT ───

If you build an AI trading agent today with OpenClaw, Hermes, or any framework, you have nowhere to deploy it. You need exchange API keys, a server, private key management, a dashboard, and a way for people to discover and copy your agent. The frameworks exist, the markets exist, the AI models exist — but there's no platform that connects them.

Meanwhile, copy trading is the most popular way people participate in crypto — but followers copy blindly. They can't verify track records, detect degrading strategies, or see how someone actually thinks about trades. As the hackathon research notes: "What people actually want to copy is how someone thinks."

Trivo bridges both gaps — a platform to launch programmable AI agents that trade across venues, with on-chain verified track records, reasoning transparency, and intelligent copy trading.

─── PROJECT DESCRIPTION ───

Trivo is a platform for launching programmable AI trading agents on Arc. Users create agents by describing a strategy in natural language, picking an AI model (DeepSeek, Claude, OpenAI, Qwen, or any OpenAI-compatible provider), selecting trading venues (perpetuals, prediction markets, LP, yield), and setting risk rules.

Every agent gets an ERC-8004 on-chain identity NFT on Arc — a unique builder code that travels with every trade, so agents can build verifiable track records and portable reputation across venues, just like Polymarket V2 builder codes or Hyperliquid HIP-3 attribution.

The agent runs autonomously on a 10-second loop: THINK (loads prices from on-chain oracle, reviews past decisions, calls AI model, saves reasoning trace) → DECIDE (calls AI for structured JSON decision) → EXECUTE (calls venue contract on Arc, reports to CopyTrading contract, saves tx hash). Every step is on-chain and every reasoning trace is saved for user review.

For self-hosted agents (OpenClaw, Hermes, custom), users register an endpoint with skill.md — Trivo sends market data, the agent returns decisions, Trivo handles execution and feeds.

All positions appear in a live feed where users can discover top performers and copy-trade with one click — with on-chain attribution and automatic fees to creators. Non-custodial via Circle MPC wallets — users retain full control of funds.

─── THE RESEARCH CONNECTION ───

The hackathon's own research papers point directly to what Trivo builds:

• "Reasoning traces are the product" (Trading-R1 paper): Every agent thinking trace is saved and viewable by users. You're not just copying trades — you're copying how the agent thinks.

• "Builder codes as every LLM agent's monetization layer" (Polymarket V2): Copy trading fees flow back to agent creators automatically. Good agents earn USDC when others copy them.

• "Slash-bonded leaderboard copy-trading" (Nansen HL research): Agents build on-chain track records via ERC-8004. Followers can verify performance before copying. Strategy degradation is detectable via on-chain PnL history.

─── AGENT ENGINE LOOP (10 SECONDS) ───

1. THINK: Load market prices from SimpleOracle → Load past decisions from memory → Call AI model for analysis → Save reasoning trace → Broadcast via WebSocket
2. DECIDE: Call AI model → Get structured JSON decision { tool, args, reasoning, confidence } → Save decision → Broadcast via WebSocket
3. EXECUTE: If trade → Call venue contract on Arc → Report to CopyTrading → Save result + tx hash → Create feed event → Broadcast via WebSocket
