🔄 Complete Data Flow

Agent trade cycle — from market data to on-chain execution

60s CoinGecko API → MarketData Service → SimpleOracle.updatePrice() ARC TX
60s Polymarket Data → MockPolymarket.createMarket() ARC TX
60s LP Fee Accrual → MockLPV3.simulateFeeAccrual() ARC TX
▽
10s Load Market Data → Load Memory → Load Wallet
THINK 🧠 LLM: "Analyze market..." → Save Reasoning Trace → WS Broadcast
DECIDE 🎯 LLM: "Open LONG BTC" → Structured Decision → WS Broadcast
▽
EXEC Tool: open_trade → MockPerp.openPosition() ARC TX
REPORT CopyTrading.reportPosition() ARC TX → Save Memory → Feed Event
▽
PnL PnL Watcher (60s) → MockPerp.closePosition() ARC TX
FEE CopyTrading.closePosition() ARC TX → FeeManager.depositFee() ARC TX
